# LogDaemon

Фоновый воркер для автоматического резервного копирования чат-лога RageMP при завершении процесса игры.

## Как работает

Воркер постоянно мониторит процесс **GTA5.exe**. Когда процесс завершается, он считывает чат-лог, вычисляет его хеш MD5 и сохраняет копию в директорию резервных копий. Если содержимое лога не изменилось (хеш совпадает с уже сохранённым) — копия не создаётся.

## Настройка

Все параметры хранятся в `Workers/appsettings.json`.

```json
{
  "RageSettings": {
    "ProcessName": "GTA5",
    "ChatLogPath": "D:\\Games\\RAGEMP\\clientdata\\console.txt",
    "BackupDirectory": "D:\\RageLogs",
    "HashIndexPath": "D:\\RageLogs\\hashes.json",
    "CheckIntervalMs": 1000,
    "AutoStart": true
  }
}
```

### Параметры

| Параметр | Описание |
|---|---|
| `ProcessName` | Имя процесса, который мониторится (по умолчанию `GTA5`) |
| `ChatLogPath` | Полный путь к файлу чат-лога клиента RageMP |
| `BackupDirectory` | Директория, куда сохраняются резервные копии логов |
| `HashIndexPath` | Путь к файлу с хеш-индексом для дедупликации |
| `CheckIntervalMs` | Интервал проверки процесса в миллисекундах (по умолчанию 1000) |
| `AutoStart` | Автоматический запуск воркера при старте системы |

## Структура данных

### Резервные копии

Файлы сохраняются в `BackupDirectory` с именем по шаблону:

```
chatlog_YYYYMMDD_HHMMSS.txt
```

Пример: `chatlog_20260906_143022.txt`

### Хеш-индекс

Файл `HashIndexPath` (по умолчанию `D:\RageLogs\hashes.json`) хранит словарь вида:

```json
{
  "a1b2c3d4e5f6...": "chatlog_20260906_143022.txt",
  "f6e5d4c3b2a1...": "chatlog_20260907_091500.txt"
}
```

Ключ — MD5 хеш содержимого файла, значение — имя резервной копии. Используется для определения изменений: если хеш нового лога уже есть в индексе, копия не создаётся.

## Запуск

Просто открыть файл `Worker.exe` и зайти в игру.
